# Fifteen-selector PMK owner preparation

This successor extends `gravity.pmk.acceptance` to prepare the six existing
owner selectors left outside the earlier nine-selector closure. The old
`pmk-acceptance.edn` and private nine-selector packets remain historical inputs;
they are not rewritten or silently refreshed. The new immutable selection and
source contract is [pmk-owner-selection.edn](pmk-owner-selection.edn).

## Exact source and consumer closure

The original nine selectors retain their names and order. The six additions in
`gravity.self-hosting.sh08-function-call-type-test` are:

| Selector | Declared owning boundary |
| --- | --- |
| `sh08-private-map-keys-entry-domain-development-kernel` | C7 complete private-entry derivation |
| `sh08-private-map-keys-entry-rejection-development-kernel` | C7 source, type, member and private-entry rejection |
| `sh08-private-map-keys-other-argument-normality-development-kernel` | C7 all-argument normality and Never behavior |
| `sh08-private-map-keys-deferred-development-kernel` | C7 deferred inference and actual call-constraint consumer |
| `sh08-private-map-keys-current-source-order-development-kernel` | C7 inference pass and acyclic inference ordering |
| `pr359-descriptor-private-map-route-reconstructs-the-complete-descriptor` | Actual C7, Effects and emitter helper plans and reconstructed descriptor consumers |

The adapter follows actual local helper calls, fixed quoted helper lookups and
direct or `apply` owner-bridge calls without evaluating them. Owner/function pairs
must occur through their declared bridge and name a definition in the matching
owner source. Quoted decoys and foreign qualified bridges do not count. The last
selector calls Effects/emitter public Map constraint/fact aliases; twenty
source edges include their dispatch to PMK constructors, header/proof/cycle and
row/fact consumers. This is a static call-site closure, not branch execution.

The fixed closure digest binds all fifteen selector roles/APIs, owner-qualified
APIs, original eight C7 edges, twenty owner edges, bridge definition hashes,
the three full owner source blobs, SH08/SH09 test source and four accepted/rejected
Gravity/Q fixture files. Changing both a supplied manifest and its observed
source digest cannot replace those independently pinned bytes. The request
predecessor is PR577's cycle-only commit `3c3241b80c3b1af991c709a4eb993583e4871d52`,
tree `bd939a5da2fa92c690c1168878afa708f5dd2830`, and composition packet SHA256
`0373ed6e53000d6612509614dcfcd22cd2062abdb9c315d8f0e170dc6462e5b4`.
The successor digest orders map and set data deterministically before hashing;
EDN round trips retain the same contract. The legacy digest is unchanged.

## Nonlaunching request preparation

A caller combines the new selection contract with a fresh `capture` inventory,
actual source/request Git bookends, observed main identity and the separately
declared predecessor. `prepare` verifies source blobs before parsing owner
definitions, exact loader resources, current Java/Clojure/JAR and ordered
classpath identities, fixtures and the complete closure. It returns the normal
development runner argv with fifteen exact selectors, without invoking it.
Future `attribute` results retain the owner contract and role closure and remain
unauthenticated reports, not semantic acceptance.

The new adapter bytes invalidate the old inventory digest. Capture current bytes;
the prior 3,316-input inventory is not reused on the strength of an unchanged
count. Runtime version/vendor and JAR hashes are observable identities, not JVM
binary attestation or an executed target result. `-J-Xmx2g` is a future maximum
heap request, not capacity, watchdog or execution admission.

Compiler-free controls use an independently fixed synthetic contract to reject
missing/foreign selectors, wrong owner declarations and routing, missing owner
source, source replacement with coherently changed hashes, fixture tampering,
replacement expected pins and wrong predecessors. The original nine-closure
adapter controls remain. No owner implementation is loaded by these controls.

## Genuine gates retained

The current-source selector is authentic source through C7 only. The three-owner
selector executes real helper plans over a constructed private-Map fixture; it
does not authenticate an end-to-end source request. Actual typed/verification/
binding/original-form joins through `build-body-effect-result`,
`verify-body-effect-result` and `p15-s23-typed-assemble-plan-products` remain
separate from this preparation. Shared native controls do not establish complete
PMK native admission.

Actual compiler/Gravity/Native/runtime and composed execution remain unrun under
the current explicit execution restriction. A later authorized execution needs
real host safeguards and a fresh matching snapshot before and after the normal
runner's actual machine-result sink. No launch request, broker/process probe,
stopped PR534 metadata retry or unknown-operation replay is made here.
PMK's other accounting families, ANE and DSE are unchanged.
