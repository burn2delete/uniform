# Quoted-data current-source port

This receipt records the bounded current-main port of useful PR591 behavior.
It is development evidence only; it does not close PR502 or any accounting
criterion.

## Scope and contracts

The current base already contains the quota-free iterative `sh08-qd-data`
walk and the current quoted-data schema. The port therefore does not restore
the historical `:shape-size` field, quote work counters, depth or width
admission, or the retired budget entrypoints.

The remaining useful source delta is the five native DATA helpers and their
four guarded C7 consumers. They inspect native headers iteratively, preserve
child order, reject metadata, unsupported carriers, foreign TreeMap
comparators, invalid List tails, zero ratio denominators, malformed extents
and ancestor-identity cycles, and do not render, hash, compare or invoke
opaque values. The quoted node, derived DATA and constraint ledger are checked
at their existing source boundaries. Executable-data lookup is iterative so a
deep quoted value does not consume the host call stack.

The recursive-function test path was already adapted on current main: it keeps
the accepted Vector type and malformed-quote rejection while omitting the
retired quote-payment and insufficient-allowance assertions. The current port
leaves that file unchanged.

## Focused evidence

The focused Clojure/JVM checks passed for the recursive quoted-data,
authentication, independent-diagnostics, and multi-node semantic kernels,
including 4,097 children. A new bounded kernel passed for a depth-192 value,
exact leaf path, iterative executable lookup, duplicate and uncountable child
IDs, and an opaque unused DATA value whose rendering callback remained
uninvoked. The adapted recursive cold-quote consumer passed. The language
boundary gate passed 6 tests and 11 assertions.

The normal full function-call namespace runner was attempted once and
interrupted with exit 130 after producing no result; it is not counted as a
pass or failure. Native compiler, Effects, emitter, runtime, broker and held
selector execution remain UNRUN. No native or runtime acceptance follows from
these ordinary Clojure/JVM checks.

The immutable source-review checkpoint's base, candidate, source hashes,
preserved contracts, removed accounting fields and nonclaims are in
`quoted-data-census.edn`. Those historical identities are not the later main
composition's identities.
