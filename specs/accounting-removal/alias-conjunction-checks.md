# Source alias conjunction checks

## Declared increment

This is the next finite check after
[source premise plumbing](alias-premise-plumbing.md), base
`cceb5c800e97506637e7319a35f78986ab279ac6`. It implements source declaration
joins, a bounded semantic family of compatibility checks, and fail-closed
diagnostic classification. It does not implement a binding-table substitution
or claim a grounded concrete alias type.

## Governing rule and supported relation

No contradictory C7/L5 clauses were found. C7 requires producer-bound
constraints, and L5 distinguishes declarations from inferred facts. The current
C7 call checker uses `sh08-ft-first-type-mismatch` for known scalar arguments
without a separate compatibility premise. Signature declaration constraints
record equality for this same scalar family.

`alias-declaration-source-check` rejoins a contribution's binding to exactly
one parameter position and declaration in its retained function source records.
The type must match that declaration. A scalar declaration is supported only
when the existing `sh08-ft-atomic-type-id` maps its actual source type symbol
to that same type. Missing/duplicate source joins, wrong types, unknown producer
tags and wrong producer-relation pairs fail source verification.

`check-alias-conjunction` retains and checks every contribution. It uses the
existing mismatch checker on adjacent verified scalar obligations, rather
than choosing a seed or assigning a candidate type. Equal scalar obligations
are compatible; incompatible mandatory scalar obligations conflict. All source
rows, unsupported obligations and provisional observations remain retained.

Bare Map/List, homogeneous List, imported-function, recursive/higher-order and
handler relations are not reduced to scalar equality. L5's bare Map rule can
admit a positional Map despite unequal type records. Those obligations require
their actual source-bound compatibility consumer and remain unsupported here;
they are not silently dropped or treated as contradictions from raw inequality.
This increment adds no union, cast, widening or first-seed selection rule.

## Grounding eligibility and precise remaining gate

Compatibility of declared restrictions alone does not establish an independent
normal value/type origin for a closed alias initialization component. The
current source census admits only matched immutable lexical/def alias equations
and supported incoming alias tails. Parameters are excluded; imports and catch
binders have different source producer roles. A type seed from those roles
cannot by itself authorize a second alias initializer for the same binding.

Consequently this check does not relax the unique-producer census or pretend
that a declaration, import, callback or handler seed is an admitted alias-value
anchor. Even compatible scalar restrictions remain `:grounding :not-established`
and `:normalization :unresolved`. An ungrounded component is not assigned a
concrete type from its previous-round observations. Mandatory constraints are
kept separately and are never erased during this classification.

The remaining implementation gate is concrete: admit an independently grounded
source fact with an exact producer/edge/binding/source witness that is compatible
with the component's unique-producer census, then consume each applicable
declared/proof/import compatibility obligation through its existing checked
consumer. For Map/List boundaries this includes the actual argument, parameter,
call and source premise required by `sh08-mp-compatibility` or
`sh08-lp-compatibility`; an alias edge or raw type pair does not supply them.
No new caller assertion or authority flag can stand in for that interface.
Until this is established, binding normalization remains unsupported rather
than selecting a declaration or provisional seed as the value type.

## Integration, refusals and diagnostic precedence

The real artifact factory reconstructs components and seed producers from its
existing source inputs. `check-retained-alias-conjunctions` rebuilds the retained
premise before checking it, ignoring cached candidate authority, member/edge
and compatibility claims. Complete fresh-result verification still compares
the entire reconstructed result. Convergence evidence and both identity copies
are synchronized; typed-core schema and binding/type maps are unchanged.

Before finishing the template, `apply-alias-conjunction-diagnostic` preserves
resource-limit and existing semantic/source diagnostics, including declared
return conflicts. When there is no such failure, or only the old bounded
nonconvergence diagnostic, a source mismatch reports `C7-VERIFY`, a mandatory
scalar contradiction reports `C7-TYPE-MISMATCH`, and missing grounding or
unsupported compatibility reports `C7-ANNOTATION`. Source failures take
precedence over scalar conflicts, which take precedence over an ungrounded
component annotation. Every component premise remains in the result.

No round/work arithmetic, refusal guard, source authentication check, inferred
binding, type table or caller policy option is removed or weakened. The original
inference loop still runs. Replacing its generic nonconvergence diagnostic with
a proved source/type failure does not confer convergence or discharge a guard.

## Evidence and nonclaims

The new compiler-free model enumerates a finite set of scalar assignments as
an independent conjunction oracle. It covers equal/conflicting obligations,
incoming-tail constraints, provisional oscillation independent of obligations,
ungrounded components, non-scalar compatibility, duplicate source witnesses,
forged source/authority/relation claims, constructors, duplicate producers and
opaque/callback inputs. It never assigns its candidate to a source binding.
Previously reviewed countermodels and SCC controls are retained unchanged.

New held Gravity controls cover actual source joins, conjunctions, preserved
unsupported obligations, cached-premise/identity replacement and diagnostic
precedence. Exact source/model review and checks belong to the publication
receipt. Actual solver, authentication/tamper and composed semantic acceptance
remain unrun/held. This is an entailed compatibility/refusal slice, not complete
alias normalization, general convergence, accounting-removal completion,
release or self-hosting evidence.
