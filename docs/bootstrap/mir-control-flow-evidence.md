## Unsupported boundaries

It does not implement general CFGs, loops, matches, exceptions, full C11
module/type/effect/safety verification, authenticated input or callback ingress,
genuine source/Core admission, B1 admission, backend/native execution,
performance, migration, release, self-hosting or seed retirement. A passing
predicate is not a certificate or verified MIR artifact. No historical failed
source, native, migration, authority pin or CI gate is retried or changed.
