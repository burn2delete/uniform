# Checked Core source relocation

## Purpose

This increment establishes the first physical source boundary between the
Uniform language implementation and the temporary Clojure bootstrap. The
`gravity.checked-core` module is a language/compiler implementation. Its
execution through the Clojure stage0 seed does not make it bootstrap-owned.

## Ownership and paths

The current semantic source is:

```text
language/compiler/src/gravity/checked_core.gravity
```

The old path,
`bootstrap/gravity/src/gravity/checked_core.gravity`, is retired by this
increment. Clojure remains the execution host through the explicit adapter at
`bootstrap/clojure/src/gravity/bootstrap_impl/components/self-hosting-sh03-sh07/00885-sh07-core-source-relative-path.clj`.
The adapter supplies a source path and seed operations; it does not own Core
semantics or grant migration authority.

The module namespace remains `gravity.checked-core` for compatibility with
existing source, plan and artifact records. This relocation changes the
repository ownership path, not the language API, module identity, or semantic
behavior.

## Evidence boundaries

Current development callers and tests that consume the source use the new
language path. Historical reports, frozen source identities and archived
attempts retain their original `bootstrap/gravity/...` path and are not
rewritten or renewed by this increment.

The source bytes are preserved exactly across the move. Path-neutral semantic
hashes and function identities remain valid only where their contracts define
them independently of the physical path. Any evidence that includes the full
path or a source-set digest must be regenerated by its owning bootstrap
workflow; this document does not assert that regeneration.

The stage1 source inventory includes the moved language source location
explicitly so the module remains present in the Clojure-hosted source artifact
while the remaining stage1 modules stay under `bootstrap/gravity/src`. The
inventory does not claim the rest of `language/compiler/src` is stage1-owned.

## Acceptance and nonclaims

Acceptance for this increment is limited to:

- the source exists at the language-owned path with unchanged bytes;
- the Clojure adapter resolves and executes that path;
- current Core development fixtures retain their accepted and rejected
  behavior and diagnostics;
- the stage1 inventory records the bootstrap source root and relocated language
  source location and includes the module.

This does not claim self-hosting, Clojure seed retirement, a complete compiler,
or a seedless release. Those claims remain governed by BOOT1, BOOT3, BOOT7 and
BOOT8 evidence.
