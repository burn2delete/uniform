# JS source emission extraction

## Governing contracts and boundary

D1/D2/D3/D6/D8/D9, C1/C14/C15, B1/B6/B13/B14, P4 and TEST2 govern
this bounded extraction into gravity.backend.js. B1/B6 backend admission still
requires verified input and declared target/profile/runtime/effect policy.
Internal data construction does not authenticate or legalize a plan.

The planned API owns target alias normalization, existing plan-shape rejection,
byte/value/write/test/instruction/ESM source, declaration text, JSON escaping,
partial source maps, package metadata and output-path data. Inputs are explicit
caller-owned plans, environments/counters, source text, target data and operation
ports. Outputs are actual ESM/declaration/JSON text and existing C14-INPUT errors.
The stage may require clojure.string; Bootstrap consumes it. It must not require
Bootstrap, CLI or release.

Bootstrap retains shared scalar legality, diagnostic construction, packet and
closed-runtime authenticity, complete manifest validation, Node execution,
publication and host policy. The JS plan adapter currently checks only source
path/string and plan/map shape. It does not reject unsupported instructions;
unknown emitter operations retain their existing empty-text fallback. Source
maps are source-unit-only, with copied historical origin labels and no per-form
or authenticated compilation provenance claim.

complete shape refusals. Compare complete bytes and logical records, hashes,
source associations and deterministic identities. Cover control flow, UTF8/NUL,
integer spelling, target aliases, recursive callback order, public arities and

Run focused, ownership/language, document/roadmap/governance and contextual lint
checks, then independent acceptance and exact CI before clean integration.

## Unsupported boundaries

No Node execution, tsc/typechecking, general MIR/domain lowering, plan legality
admission, full B6 conformance, exported API declarations, async, host imports,
nullish/exception translation, numeric computation, UI bindings, migration,
release, self-hosting or seed retirement is established. Hosted scalar spelling
and emitted stdout byte arrays do not prove general Gravity numeric semantics.
