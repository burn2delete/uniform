# Mobile native diagnostic policy data

## Contract boundary

D1, D2, D3, D8, D9, C1, C15, B1, B12, B13, B14, BOOT8 and TEST2 govern
this extraction. Three existing native functions move to gravity.backend.mobile:
source-overrides, missing-policy and domain-anchor. Native module metadata and
diagnostic ids produce borrowed overrides, missing-policy labels and domain
anchors. The backend id remains :gravity.backend/mobile, distinct from the
hosted profile and iOS target. The stage imports only clojure.core; Bootstrap
consumes it through wrappers that preserve late Var interposition.

The stage owns native projection and rule-context defaults. Refusal decisions,
failure construction, catalog streams, source admission and publication retain
their existing owners. Component and ownership records declare exact source,
consumer and test paths. The SH-18 allowlist adds only the explicit mobile
owner, with actual, wrong-slice and coherent unknown-owner controls.

## Artifacts and checks

Focused tests emit and read back an actual B12-MANIFEST diagnostic for an empty
malformed native artifact. They preserve supplied source context, hosted
profile, iOS target, and distinct permission/capability labels. Catalog rows
are compatibility examples, not ten observed semantic findings. The single
specialized-lowering metadata path preserves false and nil values; other
backend keys gain no precedence. Unknown defaults, borrowed identity,
deterministic serialization and stage/wrapper interposition remain observable.

Frozen-parent/candidate captures compare six complete original serialized
records, recompute source/input digests and retain ten actual override
refusals. The baseline completed at the clean Query source parent before any
Mobile edit. No Gravity source, compiler mode, source pin, callback policy or
admission fact changed to obtain this evidence.

## Unsupported boundaries

This is native diagnostic data extraction. Full B12 compilation, verified
MIR/UI/platform ingress, app-bundle emission or execution, platform bindings,
permissions, lifecycle/threading, null/error/callback adaptation, storage/sync,
schemas, resources, store audit and simulator/device conformance remain
unsupported. Source authentication, downstream handoff and public diagnostic
publication are outside the slice. Native proof, complete and capability
labels remain data. No held native broker, restricted factory, default frozen
Reader, package/archive/release builder or Attempt30 route executes. Release,
migration, self-hosting and seed retirement are not claimed. Independent
review, own CI/artifacts and exact clean current-main integration preflight
remain required.
