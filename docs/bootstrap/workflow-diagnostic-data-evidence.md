# Workflow native diagnostic policy data

## Contract boundary

D1, D2, D3, D8, D9, C1, C15, B1, B10, B13, B14, BOOT8 and TEST2 govern
this extraction. Three existing native functions move to
gravity.backend.workflow: source-overrides, missing-policy and step-id.
Trusted native module metadata and diagnostic ids produce borrowed overrides,
missing-policy labels and step labels. The native backend id remains
:gravity.backend/workflow-graph; the profile and target remain distinct.
The stage imports only clojure.core, and Bootstrap consumes it.

The stage owns native override precedence and rule-context defaults. Existing
wrappers retain arities and late interposition. Refusal decisions, failure
construction, catalog streams, source admission and publication retain their
existing owners. The component contract registers source/consumer/test paths;
the ownership test adds only the explicit workflow SH-18 owner and its actual,
wrong-slice and coherently substituted unknown-owner checks.

## Artifacts and checks

Focused tests emit and read back an actual B10-MANIFEST diagnostic for an empty
malformed native artifact, preserving supplied source context, distributed
profile and durable-workflow target. Catalog data retains supplied input id,
source spans, ordering, serialization and distinct effect/capability fields.
Those rows are compatibility examples, not ten observed semantic findings.
Frozen-parent/candidate captures compare six complete original serialized
records, recompute source/input digests and retain ten actual override refusals.
Tests also cover precedence, false/empty overrides, borrowed identity, unknown
defaults and stage/wrapper interposition.

The first capture helper had a syntax error before producing a baseline. That
helper/log remain nonpass history. A correctly launched frozen-parent capture
completed before source editing. No Gravity source form, compiler mode, pin,
callback policy or admission fact was changed to obtain that result.

## Unsupported boundaries

This is native diagnostic data extraction. Full B10 compilation, verified
MIR/workflow ingress, graph emission or execution, schema/migration checks,
replay/nondeterminism, idempotency/retry/compensation, capability/human-review,
taint validation, downstream handoff, source authentication and public
redaction/publication remain unsupported. Existing step, provider, review,
proof and complete labels are data, not evidence or authority. The legacy
policy label mentioning budget adds no project accounting requirement or
enforcement. No native broker, restricted factory, default frozen Reader,
package/archive/release builder or Attempt30 route executes. Release,
migration, self-hosting and seed retirement are not claimed. Independent
review, own CI/artifacts and exact clean current-main preflight remain required.
