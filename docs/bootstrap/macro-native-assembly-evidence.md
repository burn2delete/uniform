## Unsupported boundaries

Native projections are compatibility evidence, not proof of hygienic macro
execution, build-grant authority, source/C3 authentication, actual trace replay,
cache-hit admission, canonical C4/C15 conformance, migration, self-hosting,
release or seed retirement. Preserve historical C4-SIZE data without a project
quota. The legacy source prefix, publication, projection helpers and generic
digest execution remain residual host boundaries.
