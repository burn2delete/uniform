formatter equivalence, source freshness, debugger access, proofs or AI review.

No source/Core authentication, capability grant, native target execution,
performance, service publication, authoritative migration, release,
self-hosting or seed retirement is established. Held routes remain untouched.

and identity without duplicate integration credit. No Seedless, Simplify,
shared CI or main writer is part of this slice.
