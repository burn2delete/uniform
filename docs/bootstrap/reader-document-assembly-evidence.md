## Boundary, public API and dependency direction

The proposed gravity.reader/native-document-projection consumes explicit source
path/text/project context/options, seventeen captured native views and ten late
owner Vars. It owns only the original artifact-base map, native validation,
proof/conformance projection, pure-text/resource policy projection and final
artifact identity. The ten owner ports are governing document, diagnostic ids,
uncredited entrypoints, trivia records, rejected designs, native validation,
proof projection, pure-text classification, resource classification and identity.
No unlisted source-intake, product-construction, SH03, cache or authentication
callback is supplied; the listed native C2 tail operations remain explicit.
The carrier requires exactly the ten listed keys before observing views. It
does not validate callback types, dereference early, add defaults or discover
Bootstrap roots.
The destination imports no Bootstrap or downstream namespace.

All facade arities, input admission, source/SH03 authentication, product and
namespace legality, native normalization, lexical checks, hashes and integrity
construction remain before the seam. Its exception remapping stays around the
same call. The facade only unwraps the stage's artifact after that guarded
prelude. No source pin, private authority or existing refusal changes.

## Artifacts, diagnostics and identity

with admission:none and authenticates-inputs?:false. Its artifact value is the
unchanged raw legacy map. That envelope never enters validation, proof, policy
projection or hashing. Raw complete/verified/partial labels remain data.
Captured source/product references, spans, literal spelling, origin, metadata,
unsafe/review data and deterministic identities survive; no facts are invalidated.

## Unsupported boundaries

Native projection authenticates neither inputs nor callbacks. It cannot grant
source/file/provider authority, admit a C2/SH03 artifact or cache record, replace
the guarded source facade, or establish complete Reader, migration, release,
self-hosting or seed retirement. Earlier SourceC9/default Reader refusals and
all held/restricted routes remain untouched.
