# Diagnostics: private source record binding

## Contract and intended boundary

D1, D2, D3, D8, D9, C1, C2, C15, BOOT8 and TEST2 govern this increment.
Its initial base is actual main13012158ec3cff4e0f8aa7468f7f33d4a066e946,
tree22e79703f29a2a2bab3195d11fa8bfdde31f3a9a. This declaration precedes
implementation and supplies no implementation or integration credit.

The bounded change moves the existing Reader diagnostic request resolver into
gravity.diagnostics through explicit canonical-digest and missing-request
operations. The Reader wrapper retains its rule and native canonical encoder.
The stage will also orchestrate private C15 record construction, full-request
digest binding and fresh source verification from the separate original eleven
fields. Gravity C15 continues to own schema, phase availability and substitution
decisions. The seed operations remain trusted host inputs, not authenticated
source admission or proof of a correct operation provider.

Inputs are private diagnostic data, actual source fields, source invocation and
canonical digest operations. Outputs are resolved Reader compatibility data,
private C15 record/verification data or the original source-owned rejection.
The complete current C15 source must compile and emit real private records;
tests must reject malformed fields, request/candidate substitutions and digest
drift. Source plans, source text hashes, structured native producer failures,
original fields, digest requests and complete results must retain provenance.

## Dependency and acceptance boundary

gravity.diagnostics requires only clojure.core. Bootstrap supplies compiler,
runtime, canonical EDN v1/SHA-256 and Reader failure operations. The stage must
not import Bootstrap or execute the pinned Reader/H6 or historical authenticated
pipeline to create evidence. Existing C15 source is unchanged; the separate
draft647 source edits are not imported. Private source construction failures
remain unresolved and unchanged instead of being relabeled as verified data.

Private record binding is not public disclosure permission. Public projection,
secret classification/redaction, rendering, canonical stream verification,
upstream source authentication, full C15 conformance, migration, release,
self-hosting and seed retirement remain outside this increment. The existing
source verifier's digest-recomputation nonclaim is preserved; a native host
digest call is a development observation, not a new Gravity proof.

Focused positive and adversarial tests, affected carrier and native C15 tests,
language boundary, docs/roadmap/governance, exact contextual lint, independent
acceptance, own CI and clean exact current-main preflight are required before
integration. A draft PR will be maintained throughout this work.
