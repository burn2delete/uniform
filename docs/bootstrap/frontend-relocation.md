# Macro and resolution source relocation

## Purpose

This increment places the permanent C4 macro-expansion and C5 name-resolution
modules under the Uniform language/compiler project. The Clojure stage0 seed
still hosts their development and compatibility checks, but it does not own
their language semantics or source files.

## Ownership and paths

The four moved source files are:

| Module | Language-owned path | SHA-256 |
| --- | --- | --- |
| `gravity.macro` | `language/compiler/src/gravity/macro.gravity` | `0a6e58a8134c6f9dbd139617fda376cd8978223820562c1f5b214b658f1d8db1` |
| C4 compatibility facade | `language/compiler/src/gravity/compiler/c4_macro_expansion_engine.gravity` | `61314a0d94bace963758efb740859fdf7bb8214b22e1c69fe6de5478386cc574` |
| `gravity.resolution` | `language/compiler/src/gravity/resolution.gravity` | `6243c361dc86902e40965c1fcbeabaadea7d898b587d8ba987842b3c8c28b408` |
| C5 compatibility facade | `language/compiler/src/gravity/compiler/c5_name_resolution_namespace_analyzer.gravity` | `250ab4129a499bdd85b15b00abadfa095b786a2ccd728c223ea700a3f6473377` |
The module namespaces and exported names remain the legacy
`gravity.macro`, `gravity.resolution`,
`gravity.compiler.c4-macro-expansion-engine`, and
`gravity.compiler.c5-name-resolution-namespace-analyzer` forms. This is a
repository ownership change, not a semantic or API rename.

The source roots deliberately remain mixed while the compiler is extracted:
reader, syntax, diagnostics, C6 and later compiler modules, backends, and
P15 source remain under `bootstrap/gravity/src`. The Clojure adapters and
bootstrap runner remain in `bootstrap/clojure`; they execute or inspect the
language-owned files without becoming their owners.

## Active consumers and evidence boundary

Current SH-05/SH-06 adapters, focused source-coverage tests, macro/resolution
CI selectors, the current P15 compiler source manifest, and the accepted
SH-25 `.gravity`/`.qst` component-build fixtures use the language-owned paths.
Frozen reports, archived attempts, immutable B51 records, and historical
roadmap entries retain the paths that were true when they were recorded.
They are not rewritten or renewed by this relocation.

Source bytes, namespaces, export lists, diagnostics, and pinned semantic
identity values are preserved. Any evidence whose identity includes a full
path or a source-set digest must be regenerated by its owning workflow; this
document does not claim that regeneration.

## Validation and nonclaims

The relocation is accepted only when both source extensions continue through
the existing hosted checks: an accepted `.gravity` fixture and its accepted
`.qst` counterpart must exercise the component-build path, while the focused
SH-05/SH-06 tests retain their rejected-input diagnostics. The exact commands
and observed results are recorded in the pull request and kept current as
callers are updated.

This slice does not relocate the reader, syntax object model, B51 modules, P15
source, C6 `source_contract` work, or lifecycle records. It does not claim
complete compiler implementation, self-hosting, Clojure seed retirement, or
seedless release.
