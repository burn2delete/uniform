original request/candidate data. Outputs are legacy call records and actual
source kernel values/refusals with replay verification. Initial execution
evidence is limited to vector update/lookup and checked integer addition.

coherent result/request substitutions must not replace original request data.

compile without source projection. Controls retain complete source plans,

full diagnostics. Fixture source references remain explicitly unauthenticated
data; they are not canonical Reader/C5/C7 artifacts. Before/after native records
and source outputs must conserve, including identities and physical provenance.

This is an internal seed-stage increment over an experimental meta-profile
