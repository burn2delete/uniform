## Behavior and outputs

The selected Reader program path authenticates C6/compiler inputs before and
after the actual Reader-owner binding call. It checks fixed Reader identities,
physical source path, required exports, emitter identities and declared plan
labels. Matching a program returns neither an executed Reader result nor an
observed envelope state. Versions 2 and 3 share the fixed Reader dependency;
unsupported versions refuse before owner calls. Internal default arities use
source policy 2 and do not change public Core constructor defaults.

Native parent headers are inspected without traversing unconsumed source-form
payloads. Selected owner metadata is preflighted before lookup, equality,
projection or hashing. It permits only native default-comparator metadata;
foreign classes, metadata-bearing records and custom comparators refuse.
Original selected metadata and the full witness remain committed by content
identities. Reader and expression metadata use distinct digest domains.

The envelope-state helper checks C2 identity/integrity/source, retained Reader
revision and result identity, semantic/provenance envelope identities and the
selected program/path. It calls the existing descriptor/envelope owner on the
full unmodified envelope before projection. Verification failure or an
admission state other than development-unadmitted refuses. Fixed projections
then cross into the unchanged strict Core carrier, with source-interface,
verification-scope and self-hosting nonclaims retained.
