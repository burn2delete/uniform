# Versioned fresh Core construction source

## Purpose and requirements

OWN-06 requires genuine selected-source Core construction before a separately
fresh public report and the actual C11 consumer. The prior Native source
increments supply contract, Reader, expression and private-ingress dependencies.
This finite increment restores the preserved constructor and explicit C6 header
dispatch; it does not implement the remaining public report overloads.

The baseline is PR602 head cfe934c95a61241ad337f500a08222f79f047f61.
Source comes from preserved Native f66d9ff4554815b89ee7d51ee73b7961f0c33a44:
the complete 00724a body is placed in existing 00724 after its unchanged context
and artifact helpers, replacing the legacy constructor definitions. The C6
source-interface module is byte-identical to f66. Its alias is required before
the restored public entrypoint. No component registration or source pins change.

## Behavior and artifacts

Legacy context and path/text/target overloads select version 1. Explicit public
headers accept current source versions 2/3 through the shared native parser;
an explicit version-1 header is rejected rather than treated as legacy dispatch.
The C6 wrapper preserves owning C6 diagnostics. Parsing is dispatch only.

Fresh construction still validates the public context, invokes the actual
selected C6 source binding, selected Reader program and expression binding,
and binds that expression owner result around private ingress. The pinned
Gravity builder, digest sealing and Gravity replay remain actual production
calls. A sealed rejection stops before replay. The construction record retains
the source binding, graph proof, verification view and original context.

Version 2 applies the Bool branch/join grammar; version 3 checks the strict
carrier and flat Bool sequence grammar. Versioned receipts retain Reader policy
and project the plan-free expression metadata through the existing owner helper.
Private plans/manifests stay out of the public binding view. Dynamic expression
binding unwinds after ingress, including failures.

The Bool grammar require moves earlier with the constructor; the now-redundant
later require in 00740 is removed. The now-used expression metadata projection
helper in 00723 loses its targeted unused-private annotation. Function bodies
in those two dependency components are unchanged.

## Conformance evidence and limits

`tools/c6_fresh_construction_test.clj` runs 6 tests / 61 assertions after the
existing relative-policy 4/54 and Reader-policy 6/64 controls. Shared native
header parsing, C6 diagnostic translation, semantic-family grammars, carrier
validation and expression metadata projection are actual code. Public context,
source binding, Reader/expression owners, private ingress, envelope, builder,
sealing, replay and artifact production are declared oracles. Test Core and
policy products are synthetic; Bootstrap remains unloaded. No real producer,
Reader, expression compiler, authentication or Gravity replay executes.

Controls cover both explicit public overloads, early malformed/native-version
header refusal, unchanged legacy routing, selected versions at owner seams,
the expression binding's lexical lifetime, selected Reader ingress arguments,
family mismatch, metadata carrier refusal, sealed/upstream rejection before
replay, and plan-free public metadata. A deliberately false source hash from a
synthetic expression owner survives projection: this control documents that
projection cannot authenticate the owner and must not be cited as such proof.

## Remaining acceptance

Versioned public Core verification/report overloads and their separately fresh
construction remain required, followed by lexical C11 owner authentication,
builder and genuine public replay. Actual supported Core/context pairs and
positive/negative runtime results remain unaccepted. Source tests do not fill
those obligations. Exact independent source review, applicable CI, current-main
composition and coordinator integration remain separate; avoid replaying
identical or tree-equivalent prerequisites.

PR453 original-v2 evidence, PR574's unresolved final independent disposition,
PR446 UNKNOWN and operation-specific holds remain unchanged. No denied action
or held runtime/controller operation is retried. No PR552 completion, OWN-06
closure, v3 product acceptance, backend, release or self-hosting claim is made.
